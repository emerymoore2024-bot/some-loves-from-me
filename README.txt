UPLOAD TO GITHUB
1. Open your repository on the main branch.
2. Upload index.html, content.json, and the entire photos folder, preserving the photos/ paths.
3. Commit changes and allow GitHub Pages a few minutes to deploy.
4. Open your existing site URL and refresh.

REMOTE UPDATES
Edit content.json in GitHub, then commit changes. Change the daily message/photo path or add surprises and openWhen entries. Jack will see changes on his next page refresh.

PRIVACY
GitHub Pages for a public repository is public. Anyone with the URL can see the photos and messages. Do not upload anything private.

NOTE
The NFC tag opens the website. It does not itself enforce phone blocking. That needs a separate iPhone Shortcut/Focus setup.
